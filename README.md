# とけいのまちの じかんたんてい

時計の読み方を、問題に答えながら練習できる小学生向けの算数Web教材です。

## 公開ページ

[とけいのまちの じかんたんていを開く](https://tt-sensei.github.io/tokeibenkyo/)

## できること

- 時計の針を見て時刻を読む
- 時計の読み方の問題に挑戦する
- 学習の記録を確認する
- 取り組みに応じてシールを集める

## 対象

小学校低学年の算数「時刻と時間」の学習に利用できます。

## 構成

```
tokeibenkyo/
├─ index.html   教材本体（HTML・CSS・JavaScriptを含む）
└─ README.md    この説明
```

## 動作について

ブラウザだけで動作し、学習記録は利用している端末内に保存されます。
